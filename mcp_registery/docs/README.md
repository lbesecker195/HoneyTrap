# docs

Draft outreach copy for promoting the registry on third-party platforms, kept here for reference before posting.

- `github-mcp-registry-request.md` — the comment to post in GitHub's MCP registry discussion once this project's mirrored listing is live in the official MCP Registry, asking for inclusion in github.com/mcp.
- `show-hn.md` — a title, URL, and first-comment draft for a Hacker News "Show HN" submission announcing the site, meant to be posted only after an end-to-end launch check.

Neither file is rendered, served, or read by the application. They are unpublished drafts aimed at GitHub Discussions and Hacker News, not site content, so this directory has no direct effect on any page of the live site.
