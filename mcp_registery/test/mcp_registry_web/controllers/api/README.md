ExUnit tests for the JSON API controller in `lib/mcp_registry_web/controllers/api/` (`server_controller.ex`, `fallback_controller.ex`, `server_json.ex`) and for the `/llms.txt` route. `server_controller_test.exs` exercises listing and searching active servers, fetching one by raw or URL-encoded name, submitting manifests both as a full server.json payload and as flat fields, publish-token authentication that skips review, per-client rate limiting, the pending-review queue cap, and maintainer approve/reject decisions via `/api/v0/review`. It also asserts `/llms.txt` documents the `/mcp` endpoint, the `submit_server` tool, the submission URL, and the Seriously Simple Analytics script tag.

No direct effect on the live site: this is a test suite that runs in CI and locally, never against production, so no single ai.mcpharbor.dev page is tied to this directory. Its effect is indirect: passing tests are what keep `/api/v0/servers`, `/api/v0/review`, and `/llms.txt` behaving correctly for the agents and scripts that depend on them.
