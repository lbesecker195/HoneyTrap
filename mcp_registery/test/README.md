This is the ExUnit test suite for the Phoenix app. `mcp_registry/` covers the `Registry` context (creating and validating server listings, name normalization, search/filtering), the `OfficialRegistry` job that mirrors the upstream MCP registry, and the rate limiter. `mcp_registry_web/` covers the LiveViews (home search, server show page), the JSON API controller, the MCP JSON-RPC endpoint (`initialize`, `search_servers`, `get_server`, `submit_server`), error pages, and the client-IP plug. `support/` holds the `ConnCase` and `DataCase` templates plus `RegistryFixtures`, which build sample server records against a per-test Postgres sandbox transaction. `test_helper.exs` starts ExUnit and puts `McpRegistry.Repo` into manual sandbox mode.

None of this runs on the live site. It only executes locally and in CI to check that registry logic, sync behavior, page rendering, and the MCP tools behave correctly before a change is deployed, so it has no page of its own on https://ai.mcpharbor.dev.
