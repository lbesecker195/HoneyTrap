This directory holds the Ecto migrations and seed data for the `servers` and `registry_syncs` tables that back the entire [MCP server directory](https://ai.mcpharbor.dev/). The migrations define columns for name, transport, package registry, tags, tools, sync origin/timestamps, and the `article_content` field that powers the long-form write-ups shown on each listing, such as the [Context7 server page](https://ai.mcpharbor.dev/servers/io.github.upstash%2Fcontext7).

`seeds.exs` loads a starter catalogue of well-known servers (filesystem, memory, GitHub, Playwright, Context7, Supabase, Notion, Linear, Sentry, Stripe, and more) that appear live once `mix run priv/repo/seeds.exs` runs, tagged `origin: "seed"` so they're distinguishable from rows mirrored from the official MCP Registry or submitted through the site. The `origin`, `synced_at`, and `source_updated_at` columns let the background sync job tell seed, official, and locally submitted rows apart when refreshing roughly 31,000 mirrored servers.

Schema changes here determine what every search result, server detail page, and the `/api/v0` and `/mcp` endpoints can return, so changes should ship as new migrations rather than edits to existing ones.
