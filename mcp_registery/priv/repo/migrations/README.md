This directory holds the Ecto migrations that define the PostgreSQL schema behind every server listing on the site. The `servers` table (name, title, description, transport, urls, tags, tools, env_vars) backs the search and directory grid on the [MCP server search](https://ai.mcpharbor.dev/), and each row is what renders as an individual manifest page like [the Context7 entry](https://ai.mcpharbor.dev/servers/io.github.upstash%2Fcontext7). Later migrations added `origin`, `source_updated_at`, and `synced_at` columns plus a `registry_syncs` table to track the background job mirroring roughly 31,000 servers from the official MCP Registry; widened several URL columns to `text` after official listings arrived with URLs thousands of characters long; dropped a redundant "official" tag from seed data; and added `article_content` / `article_generated_at`, the fields that hold the generated SEO write-up shown on that same server page. Applying these migrations is what creates and evolves the database every part of the app reads from, including the JSON API under `/api/v0` and the `search_servers` / `get_server` tools exposed at `/mcp`.
