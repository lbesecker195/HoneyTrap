This directory holds the English Gettext translations for the Phoenix app, generated by `mix gettext.extract`/`mix gettext.merge` from `priv/gettext/errors.pot`. The only file here, `LC_MESSAGES/errors.po`, lists the standard `Ecto.Changeset` validation messages (e.g. "can't be blank", "has already been taken", "must be greater than %{number}") with every `msgstr` left empty, since English is the app's default locale and Gettext falls back to the original `msgid` text when no translation is supplied.

Because there are no actual translations here, this file has no effect on what visitors see — it is a locale scaffold for future internationalization, not live content. It is not read, rendered, or served directly by any route, and it has no impact on the live site at https://ai.mcpharbor.dev.
