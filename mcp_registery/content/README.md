This directory holds draft SEO landing-page articles, one topic per subdirectory (`best-mcp-servers`, `build-mcp-server`, `claude-mcp`, `cursor-mcp`, `install-mcp-server`, `mcp-client`, `mcp-inspector`, `mcp-server`, `mcp-tools`, `what-is-mcp`). Each subdirectory contains a single `README.md`, which is the finished long-form article itself — Markdown with `title`/`description`/`date` frontmatter, written around one MCP-related keyword phrase — not documentation about the folder.

These articles are not yet wired into the Phoenix router: none of the topic slugs currently resolve as pages, and requests to them return 404. The content cross-links to the live catalog (the homepage and individual `/servers/*` listings) and to a separate docs repository, but as of now this directory has no direct effect on the running site — no visitor or agent reaches this text through https://ai.mcpharbor.dev. It functions as a staging area for future SEO pages rather than a live part of the site, until a route or static-page pipeline is added to publish these slugs.
