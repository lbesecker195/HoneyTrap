This directory holds the Phoenix components that wrap every page on the site: the root HTML document, the shared app layout, and the reusable UI building blocks used across the LiveViews.

`layouts/root.html.heex` is the outer HTML shell rendered on every request. It loads the compiled Tailwind/JS assets, the Seriously Simple Analytics snippet, the Google AdSense script, the `llms.txt` alternate link agents use for discovery, and the light/dark theme bootstrap script. `layouts.ex` defines the `app/1` layout — the top navbar (Browse, API, llms.txt, a theme toggle, and a "Submit a server" call to action) and the footer crediting the official MCP Registry mirror and Seriously Simple Analytics — and also defines the `theme_toggle` button component it uses. `core_components.ex` supplies the flash banners and icon helper reused throughout the app.

Because this code renders on literally every request, it drives the site's global navigation, branding, and monetization. It is how visitors find the searchable directory at https://ai.mcpharbor.dev/ and the listing form at https://ai.mcpharbor.dev/submit, and it is where the AdSense and analytics scripts actually load from on every page view.
