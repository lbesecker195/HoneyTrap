This is the Phoenix web layer for MCP Registry: it turns the domain logic in `lib/mcp_registry` into the actual routes people and agents hit. `router.ex` wires up four surfaces. `live/server_live` drives the search and browse experience at https://ai.mcpharbor.dev/, the "list your server" form at https://ai.mcpharbor.dev/submit, and each listing's install snippets at https://ai.mcpharbor.dev/servers/. `controllers/llms_controller.ex` and `llms.ex` render the agent-facing index at https://ai.mcpharbor.dev/llms.txt. `mcp_controller.ex` and `mcp/` implement the registry's own tool endpoint at https://ai.mcpharbor.dev/mcp (search_servers, get_server, submit_server); `controllers/api/` separately backs the JSON API under `/api/v0`. Both surfaces submit through the shared `submissions.ex`, which authorizes, rate-limits, and validates new listings before they're saved. `components/layouts/root.html.heex` is the shared shell the three human-facing LiveView pages load through, including the Seriously Simple Analytics tag and the sitewide Google AdSense script; `/llms.txt`, `/mcp`, and `/api/v0` bypass that layout and return plain text or JSON instead. `plugs/api_analytics.ex` reports API traffic back to Seriously Simple Analytics.
